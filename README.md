# Move Plus

## Sobre o projeto

O Move Plus é um projeto acadêmico desenvolvido utilizando Node.js e Express. Seu objetivo é apresentar uma aplicação relacionada ao universo fitness, com uma página inicial e um servidor para disponibilizar informações.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express

## Funcionalidades

- Página inicial da Move Plus.
- Servidor desenvolvido com Node.js.
- Utilização de rotas HTTP.
- Consulta de informações através da rota de livros.

## Como executar o projeto

1. Clone ou baixe o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor:

```bash
npm start
```

5. Acesse no navegador:

http://localhost:3000
